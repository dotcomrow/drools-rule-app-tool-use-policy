# Settings

Generated by `scripts/generate-settings-doc.py`.

Defaults are resolved in this order:
1. Value in the ConfigMap.
2. Value set in the job manifest `env:` list.
3. Default value in the job script.

Version resolution (when VERSION/REPO_VERSION is empty or 'auto'):
- If the pom has a literal `<version>`, use it.
- Else if `<revision>` exists and is not a `-SNAPSHOT`, use it.
- Else derive a prefix from `<revision>` (major.minor) or use `VERSION_PREFIX`.
- Then append `git rev-list --count HEAD`.
